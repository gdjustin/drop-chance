# 0.001% Drop Chance

A free idle game about drop rates. **Everything is a drop:** your heroes, your gear, your features, even the save button. The odds shown in the game are the real odds.

**▶ Play in your browser: https://gdjustin.github.io/drop-chance/**

- **No real money.** No ads, no purchases, no premium currency.
- **Works on phone and desktop.** One page, nothing to install.
- **Your save stays on your device.** Nothing is sent anywhere. Back it up from More → Settings → Save text. The game also keeps 3 automatic backups (More → About).

## Public playtest

This is an early public build. Balance will change, and things will break.

- **Found a bug?** In the game, go to More → About → Report a bug. It copies a report with your version and any errors. Paste it into a [new issue](https://github.com/gdjustin/drop-chance/issues/new/choose) or the [Discord](https://discord.gg/VABkGWuMy).
- **What changed:** see [CHANGELOG.md](CHANGELOG.md), or More → About in the game.
